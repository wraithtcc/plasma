plasma

01 — about

Math, mapped to characters.

plasma computes an interference pattern of sine waves across a 2D grid, every frame, and maps intensity to a ramp of terminal glyphs and greyscale ANSI codes. The result is a slow, shifting field that runs entirely inside a text terminal.

render

Pure Python core

No compiled extensions required. Runs anywhere Python 3 runs, including over SSH.

output

ANSI greyscale

256-color ramp mapped to field intensity — from black through grey to white.

control

Live parameters

Adjust width, speed, and wave count as flags, or interactively while it runs.
